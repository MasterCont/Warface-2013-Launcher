# Suboot Games Launcher

Лаунчер частного сервера Warface 2013 (клиент 1.1.1.426): вход и регистрация по ключу
приглашения, выбор сервера, запуск игры, смена пароля. Для модераторов и
администраторов — панель управления сервером.

C# / WPF, .NET 10, без сторонних пакетов. Работает через REST API сервера
(`https://api.wf.suboot.pro`, описание — `docs/api.md` в репозитории сервера).

## Возможности

- **Игрок:** вход (сессия хранится 30 дней, зашифрована DPAPI в `%APPDATA%\SubootGames`),
  регистрация по ключу, карточка персонажа, список серверов с состоянием, запуск
  `Bin32Release\Game.exe` с одноразовым токеном, смена пароля.
- **Модератор:** игроки в сети, все игроки по 10 на странице с поиском, карточка игрока,
  сообщения, кик, баны (до 168 ч), рассылка.
- **Администратор:** точные значения опыта и денег, склад игрока (починка, срок аренды,
  количество, удаление, выдача предметов), редактор магазина (цены, скидки, сроки,
  прочность, метки, снятие с продажи, новые предложения), ключи приглашения, аккаунты и роли.
- Два оформления: «Сайт 2013» (по умолчанию) и «Как в игре», переключаются кнопкой «Оформление».

Права проверяет сервер: лаунчер только прячет недоступные разделы.

## Сборка

Нужен .NET 10 SDK (или Rider).

```powershell
dotnet build SubootLauncher\SubootLauncher.csproj
```

Один `.exe` для раздачи (с встроенным .NET, ничего ставить не нужно):

```powershell
dotnet publish SubootLauncher\SubootLauncher.csproj -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true `
  -o publish
```

`PublishTrimmed` не включать: WPF его не поддерживает.

## Структура

| Путь | Что |
|---|---|
| `App.xaml(.cs)` | запуск, выбор темы, переход вход → главное окно |
| `MainWindow` | персонаж, серверы, папка игры, «Играть» |
| `Views/LoginWindow`, `ChangePasswordWindow` | вход, регистрация, смена пароля |
| `Views/ModerationWindow` | панель модерации; `ShopPanel` — магазин, `StorageWindow` — склад, `ItemPickerWindow` — выбор предмета |
| `Services/ApiClient.cs` | клиент REST API, перевод ответов сервера на русский |
| `Services/GameLauncher.cs` | поиск папки игры и запуск `Game.exe` |
| `Services/Settings.cs` | настройки и сохранённая сессия |
| `Themes/` | оформления (`Classic`, `Game`) и общие стили (`Shared`) |
